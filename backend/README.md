# ProofChain

> Plataforma para emissão, gestão e validação de certificados digitais.

## Sobre o ProofChain

O **ProofChain** é uma plataforma SaaS desenvolvida para facilitar a emissão, gestão e validação de certificados digitais.

A plataforma permite que instituições emitam certificados de forma estruturada e disponibilizem mecanismos para que sua autenticidade possa ser verificada posteriormente.

O sistema utiliza **provas criptográficas e tecnologia blockchain** como camada de rastreabilidade e comprovação, mantendo os dados operacionais sob responsabilidade da aplicação.

## Principais recursos

- Emissão de certificados digitais
- Validação pública de certificados
- Gestão de instituições
- Gestão de usuários e permissões
- Arquitetura multi-tenant
- Geração de provas criptográficas
- Registro de evidências em blockchain
