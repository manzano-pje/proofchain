# Ollama Developer Relations GitHub Repository

---

## Visão Geral do Sistema

Ollama é um projeto de desenvolvimento de software que utiliza a arquitetura Clean Architecture para criar uma aplicação inteligente e eficiente. Este documento descreve o sistema, os princípios arquiteturais aplicados e as etapas para sua implementação.

---

## Princípios Arquiteturais Aplicados

- **Clean Architecture**: Ollama é construído de acordo com a arquitetura Clean, que separa a lógica do negócio da infraestrutura. Isso torna o código mais limpo e fácil de manter.

- **Spring Boot**: A aplicação utiliza Spring Boot para facilitar a injeção de dependências e gerenciamento automático das configurações.

- **Java 21**: Ollama é desenvolvido com base em Java 21, que oferece melhorias significativas na performance e segurança do código.

- **Spring AI**: A aplicação utiliza Spring AI para otimizar a eficiência da execução de tarefas complexas.

---

## Guia de Execução Rápida

### Rodar o App

```bash
# Instale as dependências necessárias
./gradlew bootRun
```

### Rodar Ollama

```bash
# Execute a aplicação
./gradlew run
```
