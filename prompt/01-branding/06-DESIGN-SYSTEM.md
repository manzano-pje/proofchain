Toda interface deverá seguir estes padrões.

Características:

- fundo escuro;
- tons azuis;
- contraste elevado;
- profundidade visual;
- iluminação discreta.

# Gradientes

Não utilizar fundos chapados.

Utilizar gradientes sutis.

Exemplo:

```
Dark Blue

↓

Deep Blue
```

Nunca utilizar gradientes exagerados.

---

# Blockchain Background

Utilizar elementos visuais discretos.

Exemplo:

- linhas finas;
- pontos conectados;
- redes abstratas.

Características:

- baixa opacidade;
- pouca interferência;
- somente reforço visual.

# Espaçamento

Utilizar espaçamento generoso.

Evitar interfaces compactadas.

Seções devem possuir:

Desktop:

120px - 140px

Mobile:

64px - 80px

---

# Cards

Características:

- fundo elevado;
- borda discreta;
- sombra suave;
- hover elegante.

Evitar aparência quadrada simples.

---

# Botões

## Primary

Gradiente azul.

Hover:

- mais luminoso;
- glow;
- elevação.

---

## Secondary

Outline azul.

Hover:

- preenchimento suave;
- mudança de contraste.

---

# Inputs

Características:

- fundo escuro;
- borda discreta;
- foco azul.

---

# Sombras

Utilizar sombras suaves.

Evitar sombras pesadas.

---

# Border Radius

Utilizar cantos modernos.

Padrão:

12px - 16px

---

# Objetivo Visual

A interface final deve parecer:

- premium;
- moderna;
- confiável;
- tecnológica.

Nunca parecer um template simples.
