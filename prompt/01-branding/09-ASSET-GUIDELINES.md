# PROOFCHAIN
## ASSET GUIDELINES

Versão: 2.0

---

# Objetivo

Definir como os arquivos visuais fornecidos devem ser utilizados.

---

# Assets Oficiais

O projeto poderá receber:

- Logo;
- Symbol;
- Favicon;
- Screenshot Landing;
- Screenshot Login;
- Screenshot Dashboard;
- Screenshot Validação;
- Imagem do certificado.

---

# Regra Principal

Assets oficiais possuem prioridade.

A IA não deve substituir imagens fornecidas por imagens geradas automaticamente.

---

# Logo

Utilização:

- Header;
- Login;
- Footer.

Respeitar:

- proporção;
- espaçamento;
- área de proteção.

---

# Symbol

Utilização:

- favicon;
- elementos pequenos de marca.

Não substituir o logo completo.

---

# Favicon

Utilizar somente o símbolo.

Não utilizar a marca completa em tamanhos reduzidos.

---

# Certificado da Hero

A imagem do certificado possui finalidade exclusivamente visual.

Ela representa:

- confiança;
- autenticidade;
- conceito da plataforma.

Ela NÃO representa:

- certificado real emitido;
- componente funcional;
- documento gerado pelo sistema.

---

# Organização dos Assets

Sugestão:

```
assets

├── brand

├── hero

├── illustrations

├── icons

└── screenshots
```

---

# Imagens de Referência

Screenshots enviados representam:

- estrutura;
- composição;
- hierarquia visual.

Não devem ser copiados como imagens estáticas.

Devem orientar a implementação dos componentes.

---

# Tratamento Visual

Imagens podem receber:

- sombra;
- glow;
- bordas;
- animações leves.

Não alterar identidade original.

---

# Responsividade

Todos os assets devem possuir comportamento responsivo.

Evitar:

- imagens cortadas;
- distorções;
- perda de qualidade.

---

# Resultado Esperado

Os assets devem reforçar a percepção premium da plataforma.
