# PROOFCHAIN
## VISUAL DIRECTION

Versão: 2.0

---

# Conceito Visual

O ProofChain deve transmitir:

- autenticidade;
- blockchain;
- segurança;
- inovação.

A interface deve parecer uma plataforma tecnológica premium.

---

# Estilo

Direção:

Dark Enterprise SaaS.

Características:

- fundo escuro;
- azul profundo;
- iluminação suave;
- elementos tecnológicos discretos.

---

# Fundo

Não utilizar fundo totalmente chapado.

Utilizar camadas:

```
Base Dark Blue

+

Gradiente suave

+

Elementos Blockchain

+

Glow discreto
```

---

# Gradientes

Cada seção pode possuir pequenas variações.

Exemplo:

Hero:

Dark Blue

↓

Deep Blue


Features:

Blue Black

↓

Dark Surface

O gradiente deve ser sutil.

---

# Elementos Blockchain

Utilizar:

- linhas finas;
- pontos conectados;
- redes abstratas.

Características:

- baixa opacidade;
- fundo;
- sem prejudicar leitura.

Evitar excesso de elementos.

---

# Profundidade Visual

Utilizar:

- sombras suaves;
- transparências;
- glass effect discreto;
- iluminação.

Evitar aparência plana.

---

# Certificado Hero

A imagem do certificado deve possuir:

- destaque;
- profundidade;
- glow;
- integração com fundo.

Não deve parecer uma imagem simplesmente colocada na tela.

---

# Cards

Os cards devem transmitir qualidade.

Características:

- fundo elevado;
- borda discreta;
- sombra;
- transição.

Evitar:

- caixas totalmente quadradas;
- excesso de bordas;
- aparência de formulário.

---

# Tipografia

A tipografia deve ser:

- moderna;
- limpa;
- profissional.

Títulos:

- fortes;
- objetivos;
- proporcionais.

Nunca utilizar títulos gigantes que dominem a página.

---

# Sensação Desejada

Ao abrir o site, o usuário deve pensar:

"Esta parece uma plataforma confiável de tecnologia."

---

# Referências de Qualidade

Buscar percepção semelhante a:

- plataformas SaaS modernas;
- produtos enterprise;
- ferramentas de tecnologia.

Não copiar layouts ou identidades.
