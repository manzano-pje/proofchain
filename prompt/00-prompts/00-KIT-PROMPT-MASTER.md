# PROOFCHAIN AI KIT
## Master Prompt

Versão: 2.0

---

# Objetivo

Este kit define todas as regras para construção do frontend do ProofChain.
Cada documento deste kit depende do documento anterior.
Todos devem ser analisados antes de qualquer geração de código.
Nenhum documento substitui outro.
Cada arquivo complementa o anterior.
A implementação deverá seguir rigorosamente a ordem definida neste kit.

---

# Objetivo do Projeto

Construir o frontend completo do MVP do ProofChain.

O resultado deverá possuir aparência profissional, arquitetura escalável, código limpo e qualidade equivalente a um produto SaaS comercial.

O projeto deverá estar preparado para futura integração com o backend.

Nesta etapa nenhuma API real deverá ser utilizada.

Toda funcionalidade deverá utilizar dados simulados (Mock).

---

# Escopo do MVP

O MVP deverá possuir:

- Landing Page
- Login
- Dashboard
- Validação Pública de Certificados

Todas as páginas deverão estar conectadas entre si.

A navegação deverá funcionar completamente.

# Backend

Não implementar backend.
Não implementar autenticação real.
Não implementar banco de dados.
Não implementar blockchain.
Toda comunicação deverá utilizar serviços mockados.
A arquitetura deverá permanecer preparada para integração futura com APIs REST.
