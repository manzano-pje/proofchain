### 1. STACK TECNOLÓGICA & DIRETRIZES TÉCNICAS (OBRIGATÓRIO)
* **Framework:** Vue.js 3 (Composition API utilizando `<script setup>` e TypeScript).
* **Navegação:** Vue Router 4 (com Navigation Guards para proteção de rotas autenticadas).
* **Estilização:** CSS3 Puro com Scoped CSS e CSS Variables (NÃO utilizar TailwindCSS, Bootstrap, Vuetify ou frameworks CSS).
* **Gerenciamento de Estado:** Pinia ou reatividade nativa do Vue (`ref`/`reactive`).
* **Validação de Formulários:** Validação reativa em TypeScript (Zod ou suporte nativo com TypeScript).
* **Ícones:** Lucide Vue Next (ou SVGs inline vetorizados).
* **Arquitetura de Mocks/Backend:** Padrão Service Layer (`/src/services`) lendo/gravando no `localStorage` quando `import.meta.env.VITE_USE_MOCK = true`, com estrutura desacoplada para chamadas HTTP reais via Axios/Fetch quando `VITE_USE_MOCK = false`.

### 6. REGRAS DE NEGÓCIO & VALIDAÇÕES DA CAMADA DE DADOS (`/src/services/`)

* **Lógica de Validação On-Chain:**
* Digitar `CERT-2026-2458` ou `VALIDO` aciona os Estados 1 e 2 (Sucesso/Autêntico).
* Digitar `EXPIRADO` aciona o Estado 3 (Expirado).
* Qualquer outro valor aciona o Estado 4 (Não Válido / Não Encontrado).


* **Validação de Idade:** Impede o cadastro de participantes com menos de 16 anos completos.
* **Validação de Datas:** Data de início <= data atual; Data de término >= data de início.
* **Emissão Vinculada & Anti-Duplicidade:** O participante deve estar obrigatoriamente associado a um curso ativo. Impede cadastros duplicados com dados únicos idênticos.
* **Cálculo Financeiro:** Atualiza e exibe dinamicamente no Dashboard o custo acumulado de R$ 0,80 por certificado gerado.
